## Project Overview

Drain Jet It is a Bloemfontein-based business that provides professional
drainage and high-pressure cleaning services to residential and commercial
customers.

The purpose of this project is to develop a clear, informative and
user-friendly website that improves Drain Jet It's online presence and makes
it easier for customers to access information about the organisation, its
services and contact details.

The website consists of five main pages: Home, About Us, Services, Enquiry
and Contact Us. The website also includes relevant images, navigation links
and an enquiry form to support customer communication.

The project is being developed using HTML, following the Part 1 requirement
that the web pages be created without CSS.

## Website Goals and Objectives

The main goal of the website is to provide Drain Jet It with a clear and
professional online presence where customers can easily find information
about the business and its services.

The website objectives are to:

- Provide clear information about Drain Jet It and its services.
- Make the website easy for customers to navigate.
- Allow potential customers to submit service enquiries and request quotes.
- Provide accurate contact information and business details.
- Improve communication between Drain Jet It and potential customers.
- Present the organisation's services in an organised and accessible way.
- Create a foundation that can be expanded in future project phases.

## Key Features and Functionality

The Drain Jet It website includes the following features:

- **Home Page:** Introduces Drain Jet It and provides an overview of the
  organisation and its services.
- **About Us Page:** Provides information about the organisation, including
  its history, mission, vision and background.
- **Services Page:** Presents the drainage and high-pressure cleaning
  services offered by Drain Jet It.
- **Enquiry Page:** Provides an online form where customers can submit
  enquiries and request quotations.
- **Contact Us Page:** Provides the organisation's telephone number, email
  address, physical address and operating hours.
- **Navigation:** Allows users to move easily between all five website
  pages.
- **Images:** Relevant images are used to support the website content and
  organisation branding.
- **HTML Forms:** The enquiry page uses HTML form elements to collect
  customer information and service requirements.
